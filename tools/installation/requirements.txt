# SambaAD ADWS - runtime dependencies.
#
# The server's runtime dependencies are SYSTEM packages, installed via apt
# (NOT pip). install.sh installs them for you:
#
#   python3-samba    -> provides `samba` and `ldb` (the AD backend; the version
#                       MUST match the running Samba DC -- never pip-install it)
#   python3-gssapi   -> provides `gssapi` (Kerberos; used by the net.tcp upgrade)
#   samba-common-bin -> provides `samba-tool` (SPN registration during install)
#
# There are NO pip-only runtime dependencies. Do NOT `pip install samba`/`ldb`
# (the PyPI packages are unrelated and wrong) and do NOT use
# --break-system-packages on the DC's system Python.
#
# Dev/lint/test tooling (ruff, flake8, mypy, pylint, pytest, pre-commit) lives in
# requirements-dev.txt and is only needed on a developer workstation.
